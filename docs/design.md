# 視覺設計

> 對應 `docs/architecture.md` 第 7 節「畫面清單」。畫面「有什麼元素、做什麼事」以架構文件為準;這份文件只管「長什麼樣子」。
> 可預覽的設計稿:`docs/design/chat-design.html`(用瀏覽器直接打開)。做前端時,有任何數值或排版疑問,以設計稿為準。

## 1. 設計方向:夜間的終端機

像深夜開著的一個終端機視窗。

- **冰藍只屬於「你自己」**:你的代號、你的訊息、你的輸入游標都是冰藍,一眼就能找到自己。
- **其他人的代號各有一種柔和的顏色**(依代號固定分配),多人對話時分得出誰是誰,即使大家都匿名。
- **訊息不做圓角氣泡**,改用一條細邊線標示發話者:別人的在左邊,你的在右邊。
- **最有記憶點的是輸入列**:代號和訊息都在 `>` 提示符號後輸入。
- 不使用:大寫標籤、裝飾性箭頭、漸層、陰影、為了好看而加的符號。

## 3. 字體與字級

- **只用等寬字體**。字體堆疊(依序備援):`Cascadia Mono`、`JetBrains Mono`、`SF Mono`、`Menlo`、`Consolas`、`Noto Sans Mono CJK TC`、`Microsoft JhengHei`、`PingFang TC`、`monospace`。
- **不載入網路字體**(不依賴外部服務,也不會因為字體載入而閃一下)。不同裝置上字形會略有差異,這是預期的。

| 用途 | 大小 | 粗細 |
|---|---|---|
| 一般文字、訊息內容、輸入 | 14px,行高 1.6 | 一般 |
| 畫面 A 標題 | 26px | 600 |
| 畫面 A 代號輸入 | 18px | 一般 |
| 時間、系統提示、字數、說明、提醒 | 12px(說明性文字 12.5–13px) | 一般 |
| 發話者代號、聊天室名稱、對話視窗標題 | 14–16px | 600 |

## 4. 共用規則

- **圓角**:最多 2px(按鈕、訊息塊)。唯一的圓形是名單前的小圓點。
- **邊框**:1px,顏色用「線條」。焦點外框 2px 冰藍、外移 2px(`:focus-visible`,所有可操作元素都要有)。
- **按鈕**
  - 一般:浮起色底、線條色邊框,滑過時邊框變次要色。
  - 主要:冰藍底、深色字、字重 600。
  - 停用:透明度 40%,游標顯示禁止。
- **進出提示、時間等次要資訊**一律用「次要」色、12px。
- **動態**:只有輸入提示符號 `>` 的游標閃爍(約 1.1 秒一輪,透明度降到 25%)。必須遵守系統的「減少動態效果」設定(開啟時不閃爍)。其他地方不做進場動畫、不做滑過動畫。
- **對比與無障礙**:所有可操作元素可用鍵盤到達並有可見的焦點外框;在線名單的展開按鈕標示展開狀態(`aria-expanded`)。

## 5. 畫面 A:輸入代號

整體:垂直置中的單欄,左右留白 `clamp(20px, 8vw, 120px)`,內容靠左對齊,最寬 420px 的輸入列。最上方是示範模式橫幅(僅階段一)。

| 元素 | 長相 |
|---|---|
| 示範模式橫幅 | 滿版細條,浮起色底、琥珀色 12px 文字置中,下方一條線。文字:「示範模式:訊息不會傳給其他裝置」 |
| 標題 | 「匿名聊天室」,26px / 600 |
| 說明 | 「不用註冊。取個代號就能進來,所有人在同一間。」次要色,最寬約 36 字 |
| 欄位標籤 | 「代號」,次要色 12.5px,在輸入列上方 |
| 輸入列 | 底部一條 2px 線條色底線(不做方框)。左側 `>`(冰藍、粗體,階段一可閃爍)、輸入框(18px、游標冰藍)、右側字數 `0/24`(次要色 12px)。輸入框取得焦點時底線變冰藍。占位文字:「1 到 24 個字」 |
| 錯誤提示區 | 輸入列下方固定保留一行高度(沒有錯誤時留空,避免版面跳動)。珊瑚色 13px |
| 進入按鈕 | 主要按鈕「進入聊天室」。格式不合(空白、超過 24 字)時停用 |

**錯誤提示文字(同一位置、同一樣式):**
- 「這個代號有人用了,換一個試試。」
- 「你上次的代號「○○」現在有人在用,請換一個。」
- 「這個代號含有不允許的字詞,請換一個。」
- 「代號要 1 到 24 個字,不能只有空白。」
- 「連不上聊天室,請檢查網路後再試一次。」

## 6. 畫面 B:聊天室

### 整體版面
由上到下:示範橫幅(階段一)→ 頂部列 → 連線橫幅(只在斷線時)→ 主區(訊息串 + 在線名單)→ 輸入區。

- **電腦(寬螢幕)**:主區分兩欄,左側訊息串自適應寬度,右側在線名單固定 **210px**,中間一條線分隔。
- **手機(窄螢幕)**:單欄,在線名單預設收起。

### 頂部列
面板色底,下方一條線,內距 10px 16px(手機 8px 12px)。

| | 電腦 | 手機 |
|---|---|---|
| 左 | 「#大廳」(600)+「在線 N 人」(次要色) | 「#大廳」 |
| 右 | 「你是 **代號**」(代號為冰藍 600)+ 一般按鈕「換代號」 | 右上「在線 N 人」按鈕(一般按鈕,展開名單用) |
| 第二列 | — | 「你是 **代號**」靠左,「換代號」小按鈕靠右(12px) |

> 「大廳」是暫定的聊天室名稱,可以改。

### 連線橫幅
只在連線狀態為 `reconnecting` 時出現,位於頂部列正下方、滿版。底 `#3a2f17`、下邊線 `#5a4824`、琥珀色 13px 文字:「連線中斷,重新連線中…」。連上後消失。

### 訊息串
- 內距 14px 16px(手機 12px),訊息之間間距 12px,由舊到新由上到下。
- **別人的訊息**:靠左,最寬 78%(手機 88%)。
  - 上方一行:代號(600、依 c1–c5 上色)+ 時間(次要色),間距 10px,12px。
  - 內容塊:面板色底、**左邊一條 2px 邊線(顏色與代號相同)**,右側圓角 2px,內距 7px 12px,保留換行,長字串可折行。**內容文字用一般文字色**(不跟著代號變色)。
- **自己的訊息**:靠右,同樣最寬 78%(手機 88%)。
  - 上方一行靠右對齊,代號與時間皆冰藍。
  - 內容塊:`#15303a` 底、**右邊一條 2px 冰藍邊線**,左側圓角 2px,文字靠左對齊。
- **連結**:內容中的網址只當作一般文字顯示,**不加底線、不可點、不變色**。
- **髒話**:已換成星號的文字照原樣顯示(例如 `***`)。
- **進出提示**:置中、12px、次要色,一行純文字,例如「小明 進來了」「Alice 離開了」。
- **缺漏提示**:斷線太久、中間有訊息沒補回時,置中顯示一個虛線框(1px dashed 線條色、內距 2px 10px、12px 次要色):「中間有部分訊息未顯示」。

### 自己的訊息狀態
顯示在自己訊息內容塊的下方,靠右,12px。

| 狀態 | 長相 |
|---|---|
| 傳送中 | 次要色文字「傳送中…」 |
| 傳送失敗 | 珊瑚色「傳送失敗」+ 同色底線文字按鈕「重送」;內容塊右邊線改成珊瑚色 |
| 已送出 | 不顯示任何狀態 |

### 「有新訊息」按鈕
只在「使用者正往上翻舊訊息,此時又有新訊息」時出現。冰藍底、深色字、粗體,內距 5px 14px,圓角 2px,文字:「▾ 有新訊息」。**水平置中**,浮在訊息串的底部、輸入區的上方(離輸入區約 10px)。點擊後捲到最新,按鈕消失;使用者自己捲回底部時也消失。

### 在線名單
- 面板色底,左邊一條線,內距 14px。
- 標題「在線 N 人」(13px / 600),下方清單,項目間距 6px。
- 每一項:前面一個 7px 的實心圓點(顏色與代號相同),後面是代號(依 c1–c5 上色)。
- **自己**:冰藍色,代號後面加次要色的「(你)」,並排在清單最前面。
- **手機展開方式**:點頂部的「在線 N 人」按鈕後,名單從**右側**滑出,寬 220px,蓋住畫面右半邊,其餘區域被半透明深色罩住(`rgba(4,7,10,.62)`)。再點一次按鈕或點外面的深色區塊即關閉。名單出現時按鈕的 `aria-expanded` 為 true。

### 「正在輸入」提示(新增功能)
輸入框的**正上方**一行,**永遠保留 22px 高度**(沒人輸入時是空白),避免出現或消失時畫面跳動。內距 2px 16px 0(手機 12px),12px、次要色,單行、過長時以省略號截斷。
- 一個人:「小華 正在輸入…」;兩個人:「小華、Bob 正在輸入…」;三人以上:「3 個人正在輸入」。
- 結尾的「…」會緩慢明暗閃動(約 1.2 秒一輪),這是整份設計裡第二個會動的地方;遵守「減少動態效果」(開啟時不閃動)。

### 分頁標題未讀數(新增功能)
不屬於畫面內的元素,是瀏覽器分頁標題:`匿名聊天室`;分頁在背景且有別人的新訊息時變成 `(3) 匿名聊天室`,超過 99 顯示 `(99+)`。

### 輸入區
面板色底,上方一條線,內距 10px 16px 12px(手機 8px 12px 10px)。

- 一列:輸入欄 + 主要按鈕「送出」,底部對齊。
- **輸入欄**:夜幕色底、1px 線條色方框、內距 7px 10px;左側 `>`(冰藍、粗體),右邊是多行輸入(占位文字「輸入訊息」)。取得焦點時方框變冰藍。
- **下方一行**(12px、次要色、左右分開):
  - 左:電腦顯示「Enter 送出,Shift+Enter 換行」;觸控裝置(手機)沒有 Shift 鍵,不顯示。
  - 右:字數,**只在接近上限時才出現**(約 180 字起),琥珀色,例如 `186/200`;超過 200 時送出按鈕停用。
- **斷線時**:送出按鈕停用,輸入欄占位文字改為「連線後才能送出」,下方左側顯示同一句話。

## 7. 換代號(沒有確認視窗)

頂部列的「換代號」按鈕按下去**立刻離開**,回到畫面 A,不再有確認視窗。畫面 A 的錯誤提示區(輸入列下方那一行)改顯示次要色的一般說明:「你已離開聊天室。想再進來,輸入一個代號就可以。」,開始輸入就消失。

## 10. 實作時要注意的地方

1. **顏色與數值請集中定義一份**(例如全部放在一個樣式檔最上面的變數),不要散落在各個元件裡寫死。
2. **代號顏色**用一個小函式統一計算(見第 2 節的規則),訊息串和在線名單必須共用同一個函式,否則同一個人在兩邊顏色會不一樣。
3. **「自己」的判斷用 `clientId`**(見架構文件 5.1),不是用代號比對。
4. 設計稿中的假資料(Alice、小明、阿宏、夜貓子)只是示意,不要寫死進產品;階段一的機器人名單另外放在 `mockBots.ts`。
5. 設計稿是靜態的,**沒有**寫出的行為(自動捲動規則、字數計算、Enter 鍵行為、各種驗證)以架構文件為準。
