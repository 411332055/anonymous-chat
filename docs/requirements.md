# 需求說明

## 這是什麼
一個不用登入的匿名聊天室。所有人在同一個聊天室裡。

## 誰會用
任何知道網站連結的人都可以進來用, 可以用電腦, 也可以用手機來操作。

## 使用的流程
1. 打開網頁
2. 輸入一個代號
3. 進入聊天室，看到其他人的訊息，也可以送出訊息
4. 新進來的人看得到最近 50 則歷史訊息
5. 輸入的代號如果已經有人在用,要請他換一個
6. 瀏覽器會記住代號,下次打開自動進入;想換的話按「換代號」
7. 斷線時顯示「重新連線中」,連上後補回漏掉的訊息
8. 訊息有長度限制;髒話換成星號;連結照常送出但只顯示成文字、不能點

## 畫面上要有
- 誰在線上
- 有人進來或離開時要有提示
- 每則訊息顯示代號和時間;自己的訊息靠右、別人的靠左,顏色不同
- 往上翻舊訊息時,若有新訊息,顯示「有新訊息」按鈕
- 電腦版在線名單固定在旁邊;手機版收起來,按按鈕展開
- 有人正在輸入時,顯示「○○ 正在輸入…」
- 分頁在背景時,瀏覽器分頁標題顯示未讀訊息數
- 伺服器端的規則:送出頻率限制、髒話過濾(不管訊息從哪裡來,資料庫都會檢查)

## 不需要的
- 註冊、登入
- 圖片、檔案上傳
- 多個聊天室、私訊
- 管理員、踢人、檢舉
- 修改或刪除已送出的訊息
